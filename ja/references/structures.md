# 避ける構文

## 二項対比

作り物のドラマを生む。Yだけ書く。

| 型 | 問題 |
|----|------|
| 「Xだからではない。Yだからだ。」 | 反転を予告している |
| 「問題はXではない。Yだ。」 | 型どおりの言い換え |
| 「答えはXではなく、Yだ。」 | 読める展開 |
| 「Xに見えて、実はYだ。」 | 前振りと種明かし |
| 「XではなくY」「XというよりY」 | 機械的な対比 |
| 「単なるXではない」「XにとどまらずY」 | 付け足しの逃げ |
| 「Xから、Yへ。」 | 見せかけの変身 |
| 「XはXでも、Y」 | 言葉遊びの対比 |

**代わりに:**「問題はYだ」「Yが効く」。否定の部分を丸ごと消す。

## 否定の列挙

何でないかを並べてから、何であるかを明かす。

| 型 | 問題 |
|----|------|
| 「Aでもない。Bでもない。Cだ。」 | 否定で溜める |
| 「必要なのはAでもBでもなく、Cだった。」 | 同じ型の過去形 |

**代わりに:** Cを書く。滑走路はいらない。

## 体言止めの連打と断片化

短い断片で強調すると、作り物の深みになる。

| 型 | 問題 |
|----|------|
| 「速さ。質。コスト。」 | 断片の連打 |
| 「〇〇。それだけ。それがすべて。」 | 演出された簡潔さ |
| 「これが、始まりだった。」 | 作られた啓示 |
| 見出しが体言止め＋句点の連続 | コピー風の一本調子 |

**代わりに:** 完全な文で書く。演出より中身を信じる。

## 問いかけの仕込み

中身を出す前に、中身があることを予告する。

| 型 | 問題 |
|----|------|
| 「もし〜だとしたら？」 | ソクラテス気取り |
| 「どういうことか。」 | 不要な予告 |
| 「考えてみてください。」 | 見下した促し |
| 「それでいいのです。」 | 不要な許可 |
| 「なぜでしょうか？」→すぐ答える | 自問自答 |

**代わりに:** 主張を書く。結論は読み手に出させる。

## 無生物主語の擬人化

物に人の動作をさせると、行為者が消える。

| 型 | 問題 |
|----|------|
| 「不満が改善に変わる」 | 不満は何もしていない。誰かが直した |
| 「施策が動き出す」 | 施策は動かない。誰かが始めた |
| 「答えが見えてくる」 | 誰かが考えて出した |
| 「データが教えてくれる」 | データは置いてあるだけ。誰かが読んだ |
| 「市場が評価する」 | 買った人がいる |
| 「文化が変わる」 | 人が行動を変えた |

**代わりに:** 人を書く。「チームがその週に直した」。特定の人がいなければ「あなた」を主語にする。

## 遠くからの語り手

場面の上から解説する声。

| 型 | 問題 |
|----|------|
| 「誰もこれを設計していない。」 | 実体のない観察 |
| 「これは〜だからだ。」「こうして〜なる。」 | 講義の声 |
| 「人は〜しがちだ。」 | 評論家目線 |
| 「私たちは〜しなければならない。」 | 大きすぎる主語 |

**代わりに:** 読み手を場に置く。「ある日いきなり〜と決める人はいない」より「あなたは少しずつ〜していく」。

## 受け身と行為者の隠蔽

| 型 | 直し方 |
|----|--------|
| 「〜が作られた」 | 作った人を書く |
| 「〜と言われている」 | 誰が言ったかを書く |
| 「ミスが発生した」 | 誰がミスしたかを書く |
| 「〜が求められる」 | 誰が求めているかを書く |
| 「〜が決定された」 | 誰が決めたかを書く |

**代わりに:** 行為者を文頭に置く。

## 文頭の癖

| 型 | 直し方 |
|----|--------|
| 「なぜ〜なのか。それは〜」 | 理由から書く |
| 「では、」「さて、」で段落を始める | 中身から始める |
| 「つまり、」「要するに、」が毎段落にある | 1回に減らすか、前の文を直す |
| 「そして、」「さらに、」の連鎖 | 文をつなげるか、順番で見せる |

## リズム

| 型 | 直し方 |
|----|--------|
| 三点セットの列挙 | 2つか1つにする |
| 問いを出してすぐ答える | 問いを残すか、消す |
| 段落がすべてキメの一文で終わる | 終わり方を変える |
| ダッシュ（——、─） | 消す。読点か句点にする |
| 「！」 | 消す |
| 短文の連打 | つなげる |
| 「必ずではない。完璧でもない。」 | 安心させるふりの逃げ |
| 読点が多すぎる一文 | 二文に分ける |

## 言葉の癖

| 型 | 問題 |
|----|------|
| 雑な言い切り（すべて、必ず、絶対、誰もが、誰も） | 偽の権威。具体で言う |
| 強調の副詞（本当に、非常に、まさに、しっかり） | 空の強調。phrases.md 参照 |
| 【】や絵文字で始まる箇条書き | 飾りで中身を補っている |
