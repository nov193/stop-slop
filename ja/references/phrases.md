# 削る言い回し

## 前置き

本題の前に置く予告。消して、本題から書く。

- 「結論から言うと」
- 「実は」
- 「ここで重要なのは」
- 「ポイントは〜です」
- 「率直に言って」
- 「正直なところ」
- 「ここだけの話」
- 「意外かもしれませんが」
- 「改めて言いますが」
- 「〜についてお話しさせてください」
- 「〜という話をしたい」

「〜とは何か？」で始めて自分で答える形も前置きに入る。

## 強調の杖

意味を足さずに勢いだけ足す言い回し。消す。

- 「以上です。」「これに尽きます。」
- 「ここが肝です」
- 「声を大にして言いたい」
- 「これは見逃せません」
- 「だからこそ〜なのです」

## ビジネス定型句

普通の言葉に戻す。

| 避ける | 代わりに |
|--------|----------|
| 解像度を上げる | 詳しく調べる、具体的にする |
| 刺さる | 反応がある、響く |
| 深掘りする | 調べる、詳しく見る |
| 〜の民主化 | 誰でも使えるようにする |
| ゲームチェンジャー | 大きな変化（何が変わるかを書く） |
| 腹落ちする | 納得する |
| 一丁目一番地 | 最優先 |
| 目線を合わせる | 認識をそろえる |
| 巻き取る | 引き受ける |
| ワンチーム | （具体的な分担を書く） |
| 伴走する | 支援する（何をするかを書く） |
| 価値を届ける | （届けるものを名指しする） |
| 〜をアップデートする | 〜を変える、直す |

## 副詞・強調語

強める語、ぼかす語、和らげる語は消す。

- 本当に
- 非常に
- まさに
- しっかり
- ぜひ
- 圧倒的に
- 実際に
- 根本的に
- 本質的に
- 確実に
- きちんと
- あくまで
- 少しだけ
- ちょっとした
- なんと

合わせて消す言い回し:

- 「〜の本質は」
- 「今の時代」「今日の〜において」
- 「〜という観点から」
- 「〜に関して言えば」
- 「結局のところ」
- 「言うまでもなく」

## 逃げの文末

言い切れることを曖昧にする文末。言い切る。

- 「〜と言えるでしょう」
- 「〜ではないでしょうか」
- 「〜と考えられます」
- 「〜かもしれません」（根拠のある推測でないとき）
- 「〜ような気がします」
- 「〜なのかなと思います」

## 過剰な敬語

- 「〜させていただきます」→「〜します」
- 「〜していただけますと幸いです」→「〜してください」（相手と場面に合わせる）
- 「〜となっております」→「〜です」

## メタ発言

文章が自分の構成を説明し始めたら消す。

- 「本記事では」「この記事でわかること」
- 「以下で解説します」「詳しく見ていきましょう」
- 「まとめると」「いかがでしたか」
- 「ヒント：」「ネタバレ：」
- 「ご存知の方も多いと思いますが」
- 「それはまた別の話」

## 見せずに言う

難しさや大事さを、示さずに宣言する。

- 「これは難しい問題です」
- 「これこそがリーダーシップです」
- 「ここが本当に大事なところです」

## 曖昧な宣言

大事だと言うだけで、何が大事かを書かない文。消すか、中身に置き換える。

- 「背景には構造的な問題がある」
- 「影響は大きい」
- 「これは根深い課題だ」
- 「賭け金は大きい」

何かが大事・深い・構造的だと書きたくなったら、その中身を書く。
