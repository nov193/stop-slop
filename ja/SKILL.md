# Stop Slop 日本語版

日本語の文章から、AIが書いたとすぐ分かる癖を取り除く。

原典は英語の書き癖を対象にしている。日本語版は直訳ではなく、日本語で出やすい癖に置き換えた。英語で書くときは原典（リポジトリ直下の `SKILL.md`）を使う。

## 基本ルール

1. **前置きと飾りを削る。**「結論から言うと」「実は」「ここで重要なのは」、強調の副詞、ビジネス定型句を消す。→ [references/phrases.md](references/phrases.md)

2. **型にはまった構文を崩す。**「XではなくY」の対比、否定の列挙、体言止めの連打、問いかけの仕込み、無生物主語の擬人化。→ [references/structures.md](references/structures.md)

3. **主語を人にする。**誰が何をしたかを書く。「〜が求められている」「〜が行われた」のように行為者を隠さない。「データが教えてくれる」のように、物に人の動作をさせない。

4. **具体的に書く。**「重要です」「鍵になります」「大きな意味を持つ」で終わらせない。何がどう重要かを書く。「すべて」「必ず」「誰もが」で雑に言い切らない。

5. **読み手を場に置く。**「多くの人は〜しがちです」より「あなたは〜」。一般論の高みから語らない。

6. **リズムを変える。**文の長さを混ぜる。三点セットより2つか1つ。段落を毎回キメの一文で終えない。ダッシュ（——、─）は使わない。「！」は使わない。

7. **読み手を信頼する。**言い訳、念押し、「〜と言えるでしょう」の逃げ、「それで大丈夫です」の許可を消す。言えることは言い切る。

8. **決め台詞を消す。**引用されそうな一文になったら書き直す。

## 納品前のクイックチェック

- 強調の副詞（本当に、非常に、まさに、しっかり）が残っていないか。消す。
- 受け身や「〜が求められる」で行為者が消えていないか。主語を立てる。
- 物が人の動作をしていないか（「戦略が動き出す」）。動かした人を書く。
- 「実は」「ここで重要なのは」「結論から言うと」で始まっていないか。本題から書く。
- 「XではなくY」「単なるXではない」がないか。Yだけ書く。
- 同じ長さの文が3つ続いていないか。1つ崩す。
- 段落がキメの一文で終わっていないか。終わり方を変える。
- ダッシュと「！」がないか。消す。
- 「〜と言えるでしょう」「〜ではないでしょうか」「〜と考えられます」で逃げていないか。言い切る。
- 「本記事では」「以下で解説します」「いかがでしたか」「まとめると」がないか。消す。
- 「重要です」「本質です」で止まっていないか。中身を書く。

## 採点

各項目を1〜10で採点する。

| 項目 | 問い |
|------|------|
| 直接性 | 中身を書いているか、予告しているか |
| リズム | 変化があるか、一本調子か |
| 信頼 | 読み手の知性を信じているか |
| 人間らしさ | 人が書いた文に聞こえるか |
| 密度 | 削れる箇所が残っていないか |

合計35/50未満なら書き直す。
