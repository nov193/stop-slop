# Claude Design のスライドで AI Slop を避ける

Claude Design（Slides）でデッキを作るときの提案。文章のルールは `ja/SKILL.md`、見た目のルールは `ja/design/SKILL.md` にある。ここでは、それを Slides の仕組みにどう組み込むかを書く。

## 1. 既定のデザインシステムを1つ作る

Slides は、既定に設定したデザインシステムを毎回読み込んでからデッキを作る。ルールを依頼文に毎回書くより、ここに入れるほうが確実に効く。

作るのは「紙と墨」の1セットだけにする。

| 要素 | 値 | 理由 |
|------|----|------|
| 背景 | 紙 `#F3F1EC`、濃い面 `#161616` | 真っ白と真っ黒を避けつつ、色で飾らない |
| 文字 | 墨 `#161616`、補足 `#5E5B55` | 紙の上で 4.5:1 以上 |
| 罫線 | `#D6D1C6` の 1px | 枠と影の代わりに線で区切る |
| アクセント | 1色だけ。Cannondale 案件ではなし（白黒） | 1スライドに1箇所だけ使う |
| 見出し | Shippori Mincho B1 | vault の明朝表示と揃える |
| 本文 | Noto Sans JP | 表と数字が読みやすい |
| 文字サイズ | 88 / 56 / 32 / 24 の4段 | 段を増やさない |

部品は次の5つのレイアウトだけを入れ、カード部品は入れない。

1. **1文**: 主張を1文だけ大きく置く。余白を広く取る
2. **表**: 罫線だけの表。見出し行は太字で、塗りはつけない
3. **手順**: 番号と文を縦に並べる。番号はアクセント色にしない
4. **2列比較**: 左右に同じ構造の文を置き、中央に1本の罫線を引く
5. **写真**: 写真を全面または左右半分に置き、小さなキャプションを添える

## 2. 依頼の前にアウトラインを「主張の列」で渡す

見出しがラベルになると、中身を埋めるために装飾が増える。依頼するときは、スライドごとの主張を1行ずつ先に書いて渡す。

```
デッキ: NMS エクスペディション23 の進め方
1. 10月28日までにマイルストーンだけ終わらせれば、報酬はあとで受け取れる
2. 最初の3時間はスキャナーにナニトを全部入れる
3. 船は不協和音系でインターセプターを拾うのが一番早い
…
素材: ゲーム内スクショ 6枚（添付）
ルール: stop-slop-design に従う。レイアウトは1〜5のどれかだけ
```

素材（写真、スクショ、製品画像）があれば一緒に渡す。ないと、Claude は空いた場所を図形とグラデーションで埋めようとする。

## 3. 作るときの Slides 固有のルール

デザインシステムに書き込むか、依頼文に貼る。

- 見出しの上に英字の小見出しを置かない
- 見出しは主張の文にする。1枚の見出しは全角30字まで
- `x-icon` と `x-shape` は、矢印で流れを示すとき以外は使わない
- 背景は単色。`radial-gradient` と装飾用の `svg` は使わない
- `border-radius` は写真の角だけに使い、4px までにする
- `box-shadow` は使わない
- 大きな数字は1デッキで2回まで。単位と出典を同じスライドに書く
- フッターはページ番号だけ。デッキ名は繰り返さない
- 出典と補足はスピーカーノートに入れる
- 同じレイアウトを3枚続けない。表が続いたら、次は1文のスライドにする

## 4. 納品前に自己採点させる

依頼の最後に次の1行を足す。

```
公開前に stop-slop-design の納品前チェックを全項目で採点し、落ちた項目を直してから公開して。
```

直してほしい箇所は、デッキのコメント機能でスライドに直接書く。「もっと良くして」ではなく「見出しを主張の文に」「カードをやめて表に」のように、ルールの言葉で指示する。

## 5. 試す順番

1. 「紙と墨」のデザインシステムを作り、既定に設定する
2. NMS のデッキを、主張の列から作り直す
3. 前後を並べ、残った癖をこのファイルとデザインシステムに足す
4. Cannondale のディーラー向け資料で、白黒のまま使えるか確かめる
